This is the feature request exactly as it arrived, before any review. It is kept unchanged so the [review log](review-log.md) can quote it. The version the AI was given is the [reviewed spec](spec.md).

**Discount codes**

We want to run promotions. Admins create discount codes and customers enter a code when they place an order to get money off.

- A code is either a percentage off or a fixed amount off.
- Codes can have an expiry date.
- Codes can have a usage limit.
- Some codes need a minimum order amount.
- One code per order.
- The order should show the discount.
- Codes are not case sensitive.
- Admins can turn a code off.
